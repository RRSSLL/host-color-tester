# Host Set Color Tester

Try backdrop, blazer and shirt colors on an illustrated on-camera host (bald, bearded, fair skin) before buying wardrobe or painting a set.

**Open the tool:** https://rrssll.github.io/host-color-tester/

## What it does

- Live 16:9 preview in a medium close-up, centered or on a third, with an optional speech-bubble lower third.
- Swatches, color pickers and hex inputs for the backdrop, blazer, shirt, skin tone and beard.
- Camera checks that flag a blazer blending into the backdrop, a face that gets lost against the wall, a beard melting into the shirt, and colors likely to clip or band after YouTube compression.
- Grayscale view and a thumbnail-size preview.
- Shuffle with locks, which only suggests combinations that pass the checks.
- Saved looks (in your browser), with PNG export of single looks, a contact sheet, or everything as a ZIP.

Screens only approximate fabric, so test finalists on camera.

## Running it

It's a single `index.html` file with no build step. Open it in a browser, or serve the folder with any static host.
